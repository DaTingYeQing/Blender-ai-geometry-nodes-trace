## 变更记录

### 2026-11-06：移除 return 边与 between 卡片

- `bltrace` 不再记录 return 边：删除 `returns.bin`、`bltrace_dump_returns`、
  `bltrace_return_count` 以及 exit 钩子里的 return 边写入。
- `covtrace_hook.c` 删除 `covtrace_calls_dump_returns` /
  `covtrace_calls_return_count` 导出；`calls` 闸门不再产出 `returns.bin`。
- 删除 `cards/returns.py` 与 `cards/between.py`；不再产出
  `return.json`、`between.json`、`boundary.json`。
- 保留 `bltrace_exit`：调用栈配对和 timing 的 self/inclusive 仍依赖它。
- 卡片顺序改为 `edge -> disasm -> coverage -> timing -> metrics -> filter`。

### 2026-11-06：rva 身份统一与 --test

- 函数身份统一为 **rva**：`edge.json` / `return.json` / `between.json` /
  `boundary.json` / `disasm.json` / `timing.json` / `functions.jsonl` 都带 rva。
- 修复 `functions.bin` 的 `rva + 1` 偏移：`edge` 卡片读取时减 1，统一到
  原始 RVA 空间；`edge.json` 函数数从 2,269 恢复到 2,330。
- `edge.json` 的符号键改为 rva，不再按 `(name,file,line)` 合并；
  `edges[]` 带 `caller_rva / callee_rva`。
- `return.json` 改为按 rva 精确匹配：4,356 / 4,356 全部匹配，0 unmatched。
- `between` / `boundary` 的图遍历改为 rva；`boundary.start/finally` 从
  名字数组改为 `{rva,name,file,line}` 对象。当前 between 291、start 32、
  finally 32。
- 删除 `only_call` 卡片与 `only_call.json`；出度统一从 `edges.bin` 按
  caller rva 统计不同 callee 数，写入 `functions.jsonl.out_degree`。
- 新增 `metrics` 卡片：`disasm.json + timing.json + edges.bin ->
  functions.jsonl`；一行一个函数，当前 2,330 行、36 列。
- `disasm` / `timing` / `return` 改为内部中间产物：默认写 `_internal/`，
  卡片跑完后删除；`run` / `translate` 新增 `--test`，只有传了才把这三个
  JSON 发布到输出目录顶层。
- `functions.jsonl` 删除完全可派生的字段（calls / hook\_calls / real\_calls /
  logic\_calls / only\_call / branchless / tiny / forwarder\_candidate /
  tail\_thunk / decode\_error / trailing\_pad / hook\_balanced），公式记录在
  首行 `_meta.derived_removed`。
- `disasm.json` 移除 `symbol.kind / tags` 和 `meta.symbol_kinds`；名字
  分类不再参与筛选。
