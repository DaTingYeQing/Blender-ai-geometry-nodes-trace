This file is the single CMake entry point for the Blender project. It enforces out-of-source builds, sets `cmake_minimum_required(VERSION 3.10)`, and activates a curated set of `cmake_policy` versions (CMP0003/0005/0010/0014/0068/0074/0087/0119/0144/0177) to normalize behavior across generators. Custom tooling lives under `build_files/cmake/`: module paths are extended to include `${CMAKE_SOURCE_DIR}/build_files/cmake/Modules` and `${CMAKE_SOURCE_DIR}/build_files/cmake/platform`, then `build_files/cmake/macros.cmake` is included to provide the `blender_project_hack_pre/post()` wrappers around `project(Blender)`. Compiler support is validated against minimums (GCC ≥ 11, Clang ≥ 8, MSVC ≥ 1928 / VS 2019 16.9.16) before including `build_files/cmake/have_features.cmake` for feature detection. Output artifacts are redirected to `${CMAKE_BINARY_DIR}/bin` and `${CMAKE_BINARY_DIR}/lib`, with multi-config-aware test output under `bin/tests/<CONFIG>/`. Version defines like `BLENDER_WIN_APPID` are injected as compile definitions on Windows. The file delegates most logic to the subdirectory tree under `build_files/cmake/`, making it a thin orchestrator rather than a monolithic script.
