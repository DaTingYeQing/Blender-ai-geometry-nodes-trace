- 路径常量集中在 `directories.py` 中通过 `os.path.join(ROOT, ...)` 组装，避免在各脚本中硬编码绝对路径。
- 可复用数据结构采用 `dataclasses.dataclass(frozen=True)` 定义不可变记录（如 `Product`、`CardRegistration`）。
- JSON 状态文件采用先写 `.tmp` 再 `os.replace` 原子写入，保证状态文件完整性。
- 错误信息统一通过 `fail(message)` 或抛出 `RuntimeError` 并以 `>> ` 前缀向 stderr 输出诊断日志。
- 对外部工具的调用通过 `directories.py` 导出的 EXE 路径常量完成，而非直接使用裸命令名。
