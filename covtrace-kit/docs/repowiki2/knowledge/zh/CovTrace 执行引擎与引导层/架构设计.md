本模块是 CovTrace 项目的顶层骨架，由四个文件构成清晰的层次：
- `directories.py`：集中声明外部工具路径（Blender/LLVM/Graphviz）、项目根目录与子目录常量，以及 `ENGINE_SCRIPT` / `BOOTSTRAP_SCRIPT` / `VALIDATE_SCRIPT` 等脚本入口，作为全工程的路径单点。
- `registry.py`：以 `@dataclass(frozen=True)` 定义 `Product`、`CardRegistration`，并维护全局 `PRODUCTS`、`GATES`、`CARDS` 注册表，将 `cards.*` 中的翻译卡与 `gates.*` 中的闸门统一暴露给引擎。
- `bootstrap.py`：在 Blender 进程内运行，解析 CLI（`--eval/--work/--node/--blend/--obj/--mod/--param/--phase/--measure-node`），通过 `infra.target` 加载并合并目标描述，打开 `.blend` 后定位对象与 geometry nodes modifier，注入 `bpy`/`time` 上下文调用 eval 脚本的 `evaluate(ctx)`，并提供 `set_value`、`touch_inputs`、`instance_count` 等运行时钩子；同时支持通过 `--phase before|after` 对测量点进行 rewire 并在 boundary 处输出 JSON。
- `engine.py`：独立于 Blender 的编排器，负责调度 `bootstrap.py` 执行、收集 raw 产物到 `cache/<node>/<hash8>/`、失败时归档 `.failed-<stamp>` 目录并按时间裁剪缓存、通过 `ThreadPoolExecutor` 并发构建卡片（coverage 单独线程），最终写出 `out/` 下的公开产物并清理 `_internal` 目录。
依赖方向单向向下：`engine.py → registry/directories → cards.*`，`bootstrap.py → gates.base + infra + frag.targeting`，二者不互相 import。
